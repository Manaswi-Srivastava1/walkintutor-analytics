# Manaswi Srivastava | Portfolio Website

Personal portfolio of **Manaswi Srivastava**, a final-year BCA student at Deen Dayal Upadhyaya Gorakhpur University, focused on **data engineering, cloud analytics and full-stack development**.

**Live site:** https://manaswi-srivastava1.github.io

## Features
- Interactive background of connected dots that react to the mouse
- Rotating 3D cubes and glowing color blobs built with CSS
- Typing animation for my roles
- Animated stat counters and scroll-reveal sections
- Scrolling skills strip and a scroll progress bar
- Responsive layout for phones, tablets and laptops
- Respects the "reduce motion" setting for accessibility

## Sections
Hero, Projects, Skills, Experience and training, Education and certifications, Contact

## Built with
- HTML5
- CSS3 (custom properties, grid, flexbox, keyframe animations)
- Vanilla JavaScript (canvas, IntersectionObserver)
- No frameworks or libraries

## Project structure
```
.
├── index.html   # page content
├── style.css    # colors, layout and animations
├── script.js    # particles, typing effect, counters, scroll effects
└── README.md
```

## Run it locally
1. Download or clone the repository.
2. Open `index.html` in any browser.

```bash
git clone https://github.com/Manaswi-Srivastava1/Manaswi-Srivastava1.github.io.git
cd Manaswi-Srivastava1.github.io
```

## Customize
- **Colors:** change the variables at the top of `style.css` (`--cyan`, `--violet`, `--green`).
- **Typing roles:** edit the `roles` list in `script.js`.
- **Content:** edit the text in `index.html`.

## Deploy
This site is hosted free with **GitHub Pages** (Settings, Pages, branch `main`, folder `/ (root)`). It also works on Netlify and Vercel.
